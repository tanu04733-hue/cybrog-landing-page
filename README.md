> **A premium futuristic cyberpunk landing page showcasing next-generation cybernetic augmentation, neural integration, and artificial cognitive co-processing.**

## 🌟 Overview & Aesthetic

**CYBORG** is an ultra-premium, dark-themed cyberpunk web experience designed to immerse users into the world of post-biological human evolution. Built with a focus on cutting-edge design patterns, glassmorphism, glowing neon illumination, and reactive interactive components.

### 🎨 Visual & Design System
- **Cyberpunk Dark Palette**: Deep obsidian background (`#030307`), neon cyan (`#00f0ff`), electric blue (`#0088ff`), cyber purple (`#a855f7`), and emergency crimson accents.
- **Glassmorphism**: Multi-layer frosted translucent cards with `backdrop-filter: blur(14px)`, glowing neon borders, and cybernetic angular chamfered edges (`polygon(...)`).
- **Typography Hierarchy**:
  - `Orbitron`: Futuristic techno headers and brand title.
  - `Rajdhani`: Tactical subheadings and cybernetic labels.
  - `Space Grotesk`: Crisp, modern high-legibility body prose.
  - `JetBrains Mono`: System telemetry codes, data tags, and diagnostic readouts.
- **Animations & HUD Elements**:
  - Interactive live particle canvas with cursor attraction.
  - Laser scanline beam sweeping down the hero cyborg frame.
  - Rotating HUD reticle rings and animated compass markers.
  - Real-time UTC clock and micro-fluctuating synaptic latency simulator.
  - Synthesized Web Audio API sci-fi sound effects engine (zero external audio files).

## 🛠️ Tech Stack & Architecture

- **Markup**: Pure Semantic HTML5 (WAI-ARIA accessibility, landmarks, roles, and schema-friendly structure).
- **Styling**: Vanilla CSS3 (Custom CSS variables, Flexbox & Grid, Clip-path geometry, Keyframe animations, Glassmorphism, and responsive breakpoints).
- **Scripting**: Vanilla JavaScript ES6+ (No external heavyweight libraries or dependencies required):
  - Canvas 2D API for particle network.
  - Native Web Audio API for synthesized cybernetic sound effects.
  - Native `IntersectionObserver` for performant scroll-reveal and counter triggers.
  - 3D perspective mouse physics for card tilt and hero parallax.

## 💻 How to Run the Website

### Method 1: Direct Browser Launch (Easiest)
Simply double-click `index.html` or drag and drop `index.html` into any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari).

### Method 2: Python HTTP Server
If Python is installed on your machine:
```bash
# In the project directory:
python -m http.server 8000
```
Then navigate to: `http://localhost:8000`

### Method 3: Node.js / npx serve
```bash
# In the project directory:
npx serve .
```

### Method 4: VS Code / IDE Live Server
If using VS Code or an Antigravity/IDE workspace, right-click `index.html` and select **"Open with Live Server"**.
